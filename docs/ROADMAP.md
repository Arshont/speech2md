## 1. Автоподбор модели (model advisor)

**Что:** при первом запуске — сводка железа (VRAM/RAM/CPU), таблица моделей с пометками
«влезает/нет» и рекомендация; Enter подтверждает, либо вводится имя модели вручную; выбор
сохраняется. Команда `speech2md models` (+ `--setup`, `--set <имя>`) и раздел
«Choosing a model» в README.

**Зачем:** новичок не знает, что такое large-v3-turbo и сколько VRAM ему нужно; сейчас
дефолт может просто не влезть в слабую карту.

**Статус:** дизайн согласован (2026-09-06), осталась спека.
**Зависимости:** тянет за собой конфиг-файл (#2) — выбор надо где-то хранить.

## 2. Конфиг-файл настроек

**Что:** JSON в пользовательской папке (`%APPDATA%\speech2md\` / `~/.config/speech2md/`):
модель по умолчанию, язык, форматы, timestamps. Приоритет: флаг CLI → конфиг → дефолт.

**Зачем:** не набирать одни и те же флаги; фундамент для #1.

## 3. Публикация на PyPI

**Что:** проверить свободность имени, собрать sdist/wheel, GitHub Actions workflow
«тег → публикация», бейдж версии в README, инструкция `pip install speech2md`.

**Зачем:** главный канал дистрибуции для Python-инструмента; строка в резюме.
**Зависимости:** нужен репозиторий на GitHub.

## 4. Watch-режим папки

**Что:** `speech2md --watch <папка>`: следить за появлением новых аудиофайлов и
транскрибировать автоматически (пример сценария: папка синхронизации диктофона).

**Зачем:** «поставил и забыл» — записи с телефона сами превращаются в заметки.

## 5. JSON-вывод

**Что:** `--format json`: сегменты с таймкодами, язык, метаданные — машиночитаемо.

**Зачем:** интеграции и скрипты поверх speech2md; дёшево — рендереры уже изолированы.

## 6. Перевод в английский

**Что:** `--translate`: Whisper умеет переводить любую речь в английский текст (task=translate).

**Зачем:** конспект иностранного подкаста по-английски; почти бесплатно — флаг уже есть в API.

## 7. Бенчмарки на реальном аудио

**Что:** прогнать длинную реальную запись (подкаст/лекция, RU и EN) по всем моделям,
замерить скорость и субъективное качество, таблицу — в README.

**Зачем:** сейчас в README замеры только на коротких TTS-сэмплах; честные цифры — доверие.

## 8. Запись с микрофона

**Что:** `speech2md --mic`: запись до Ctrl+C, затем транскрипция; следующий шаг —
потоковое распознавание близко к реальному времени.

**Зачем:** голосовые заметки без диктофона; самая «вау»-фича для демо.
**Риски:** новая зависимость для захвата звука (sounddevice), выбор устройства, буферизация —
самая сложная фича после диаризации.

## 9. Диаризация спикеров

**Что:** разметка «кто говорит»: реплики в Markdown подписываются Speaker 1/2/… (pyannote).

**Зачем:** протоколы встреч и интервью — главный сценарий длинных записей.
**Риски:** pyannote тянет torch (~2 ГБ), нужен токен Hugging Face, медленно на GTX 1060;
возможно, отдельный extra `pip install speech2md[diarize]`.

## 10. CUDA-библиотеки из pip на Linux

**Что:** подключать cuBLAS/cuDNN из pip-пакетов `nvidia-*` и на Linux (preload через
ctypes), как уже сделано для Windows в `engine.py`; сейчас там иногда требуется вручную
прописывать `LD_LIBRARY_PATH`.

**Зачем:** после PyPI аудитория расширится за пределы Windows — GPU на Linux должен
работать так же «из коробки».
**Зависимости:** логично выпустить в одном релизе с #3 (PyPI).

## 11. Бэкенд для Apple Silicon (исследование)

**Что:** CTranslate2 не поддерживает Metal/MPS — на M-чипах работаем только на CPU
(быстром, через Apple Accelerate, но GPU и Neural Engine простаивают). Исследовать
сменные движки: mlx-whisper или whisper.cpp с Metal как альтернативный бэкенд.

**Зачем:** полноценная скорость на Mac.
**Риски:** это архитектурная фича «сменные бэкенды», а не правка; низкий приоритет,
пока нет пользователей на Mac.

## 12. «Время на час аудио» в таблице моделей

**Что:** заменить в таблице `speed vs large-v3` на понятную колонку «1 час аудио ≈ N минут»,
рассчитанную под железо пользователя (класс GPU / быстрый CPU / слабый CPU).

**Зачем:** пользователь мыслит «сколько ждать», а не множителями; сейчас
относительная скорость поясняется легендой (0.2.0), но абстракция остаётся.
**Зависимости:** #7 (бенчмарки) — без реальных замеров прикидка может врать в 1.5–2 раза.
